# 通用应用框架 · 原型与 UI 规范

> 版本 v0.1 ｜ 状态：草案 ｜ 关联：[PRD-005 管理后台模板](./prd/prd-005-admin-template.md) ｜ [PRD-006 代码生成器](./prd/prd-006-code-generator.md) ｜ [架构设计](./20-architecture.md) ｜ [API 文档](./40-api-spec.md) ｜ [数据字典](./30-data-dictionary.md) ｜ 更新：2026-10-09
>
> 定位：定义后台模板（M5）与生成器产出页面（M6）的**视觉与交互基线**。本文件是设计与前端的双方契约——PRD-005 说「做什么」，本文件说「长什么样、怎么交互」。
>
> 交付物形态：先出低保真原型（本文线框）确认布局与流程 → M5 实现时用 Element Plus 落地高保真 → 关键页面截图回填本文第 10 节。

## 1. 设计原则

| 原则 | 说明 |
|---|---|
| 配置驱动 | 页面 = `<CrudTable>` + 字段配置；新增列表页 ≤ 80 行（PRD-005 AC） |
| 权限同源 | 菜单、路由、按钮三处权限码均来自后端 `permissions.code`，前端不自定义 |
| 状态完备 | 每个视图必须定义加载 / 空 / 错误 / 无权限四态，不允许只有理想态 |
| 反馈即时 | 写操作成功提示、失败按错误码给可执行建议、危险操作二次确认 |
| 一致优先 | 不追求视觉个性；后续换皮肤只改主题变量，不改业务组件 |

|---|---|---|---|
| 主色 | `--color-primary` | `#2F6BFF` | `#5B8CFF` |
| 成功 | `--color-success` | `#18A058` | `#36AD6A` |
| 警告 | `--color-warning` | `#F0A020` | `#F2C037` |
| 危险 | `--color-danger` | `#D93026` | `#E0574D` |
| 信息 | `--color-info` | `#4098FC` | `#5AA8FF` |
| 文本主 / 次 / 弱 | `--text-1/2/3` | `#1F2329 / #4E5969 / #86909C` | `#E5E6EB / #A9AEB8 / #7A7F8A` |
| 背景 / 卡片 / 边框 | `--bg / --surface / --border` | `#F5F7FA / #FFFFFF / #E5E6EB` | `#17171A / #232324 / #2E2E30` |

### 2.2 字号、间距、圆角

| 项 | 取值 |
|---|---|
| 字号 | 标题 20/16、正文 14、辅助 12；行高 1.5 |
| 间距 | 4 / 8 / 12 / 16 / 24（页面留白 16，卡片间距 16） |
| 圆角 | 按钮 4、卡片 8、弹窗 8 |
| 层级 | 侧边栏 200、顶栏 56、卡片阴影 `0 1px 3px rgba(0,0,0,.08)` |

> 依赖 Element Plus 主题变量覆盖，禁止在组件内写死颜色。
>
> **实现状态（2026-10-16，PRD-010 E-15）**：本表两列取值已逐项落到 `apps/admin-web/src/styles/variables.css`（浅色 `:root` / 暗色 `html.dark`），并由 `src/styles/__tests__/theme-tokens.test.ts` 锁定（改值即红）；业务组件零颜色字面量同由该单测扫描强制。派生档（`light-3/5/7/8/9`、`dark-2`）按主题分流——浅色向白混、暗色向黑混，取值按混色公式预计算为静态值（不用 `color-mix()`：构建期 CSS 管线会静默丢弃该声明，详见 ADR-0015「验证与踩坑记录」）；主题切换为三态（浅色 / 暗色 / **跟随系统，缺省**），系统主题变更即时生效。决策与取舍见 [ADR-0015](./adr/0015-dark-mode-tokens.md)。

- 侧边栏支持折叠（≥1280 展开，768–1280 自动折叠为图标，<768 抽屉式）。

- 多标签页：打开过的路由保留标签，支持刷新与关闭其它。

## 5. 关键页面原型

### 5.1 登录页

```
┌─────────────────────────────────────────┐
│   [Logo]  通用应用框架                    │
│                                         │
│   用户名  [________________]             │
│   密  码  [________________] 👁          │
│   验证码  [______]  [ 图形验证码 ]        │
│   ☑ 记住我                               │
│   [            登 录           ]         │
│   忘记密码？  还没有账号？注册（可关）      │
└─────────────────────────────────────────┘
```

- 失败按错误码提示：`3001` 用户名或密码错误（含剩余尝试次数）、`3004` 账号已锁定（显示解锁时间）、`9003` 请求过于频繁（按 `Retry-After` 倒计时）。
- 登录后跳回 `redirect` 原路径，未授权跳 `/403`。

### 5.2 列表页（标准 CRUD，`<CrudTable>`）

```
查询区：关键字｜状态▾｜创建时间区间｜[查询][重置][展开▾]
工具栏：[+ 新建][批量删除（需二次确认）]        [列设置][导出]
表格：☑｜业务列…｜状态标签｜创建时间｜操作（编辑/删除/更多▾）
分页：共 N 条｜每页 20▾｜页码

状态四态：
  loading → 表格骨架屏（≥300ms 才显示，避免闪烁）
  empty   → 空插画 + “暂无数据” + [新建] 引导
  error   → 错误块 + [重试]（展示 traceId 后 6 位，便于报障）
  403     → 整页替换为无权限视图（不显示表格结构）
```

配置示例（页面代码 ≤ 80 行）：

```vue
<CrudTable
  :columns="columns"
  :search-form="searchForm"
  api="/orders"
  permission="order"
/>
```

### 5.3 表单弹窗

- 新增/编辑用抽屉（字段 > 8 个）或弹窗（≤ 8 个）；编辑时抽屉标题带记录标识。
- 字段控件按类型映射（与数据字典 1.3 一致）：文本 → 输入框；枚举 → 下拉（取 `dict_items`）；金额 `decimal` → 金额框（**字符串**传输，禁浮点）；`*_id` → 关联选择（远程搜索）；`datetime` → 日期时间选择器（提交转 UTC ISO 8601）；`json` → 只读 JSON 查看器（编辑需显式开启）。
- 校验：前端先按规则提示，服务端 `1001` 时渲染 `data.details` 字段级错误到对应表单项。
- 底部固定操作条：`取消` `保存`；保存中禁用防重复提交。

### 5.4 角色授权（权限树）

```
┌──────────────────────────────────────────────┐
│ 角色：运营主管   [复制角色] [保存]            │
│ 数据范围：( )全部 ( )本组织及下级 ( )本组织 (•)仅本人 │
│ ─────────────────────────────────────────── │
│ ☑ 系统管理                                    │
│   ☑ 用户管理                                  │
│     ☑ 查询  ☐ 新建  ☐ 编辑  ☐ 删除  ☐ 分配角色│
│   ☑ 角色管理      （菜单 / 按钮 / 接口三层）   │
│ ☐ 订单管理                                    │
│   ☐ 查询  ☐ 退款                              │
└──────────────────────────────────────────────┘
```

- 半选态表示部分子项被勾选；保存走 `PUT /roles/:id/permissions`（全量覆盖），提交前提示「将覆盖原有授权」。
- 数据范围四档与数据字典 `roles.data_scope` 一致（`all` / `org_below` / `org` / `self`）。

### 5.5 审计日志详情

抽屉展示：操作人、时间（本地时区）、IP、模块/动作、traceId（可复制）、**字段级 diff**（`before_value` → `after_value`，敏感字段显示 `***`）。

### 5.6 队列与任务（M7）

顶部概览展示驱动、积压量、执行中、死信数、成功率和平均耗时。队列明细、死信、定时任务分三个标签页；死信支持详情、单条重放和清理，队列支持暂停/恢复与清空等待任务，cron 支持手动触发。查看使用 `system:queue:list`，变更使用 `system:queue:manage`。

### 5.7 生成器产出页面（M6）

与标准列表页一致，由生成器输出 `api/<model>.ts` + `views/<model>/index.vue` + `views/<model>/form.vue`；菜单与权限点随 seed 注册，无需手工接线。

## 6. 组件规范

| 组件 | 约定 |
|---|---|
| `<CrudTable>` | 配置 `columns / searchForm / api / permission` 四要素；内置分页、排序、批量选择、列设置、导入导出钩子 |
| `<DictSelect>` | 由 `useDict(code)` 取字典项，禁止硬编码枚举 |
| `v-permission` | `v-permission="'order:refund'"`，无权限移除 DOM；**服务端仍必须校验** |
| `<FormDialog>` | 统一校验、提交中禁用、错误回显 |
| `<StatusTag>` | 状态统一用标签（颜色取自字典项 `color`） |
| `<Empty> / <ErrorBoundary>` | 空态与错误态统一组件，带重试插槽 |

## 7. 交互规范

| 场景 | 规则 |
|---|---|
| 请求失败 | 统一拦截器按错误码转提示：`3001` 跳登录、`3003` 静默刷新后重试一次、`9001` 提示「已上报，traceId：xxx」、`9003` 提示退避 |
| 无感刷新 | 401 且 refresh 有效 → 刷新 token → 重放原请求；并发刷新共用同一 Promise，避免多次刷新 |
| 危险操作 | 删除、禁用、重置密码、改密必须二次确认（输入确认或弹窗确认） |
| 写操作 | 成功 toast（`Success`）；失败留在页面不关闭弹窗 |
| 导出 / 批量 | 走异步任务 → 返回 `jobId` → 进度条 + 完成后下载；不阻塞页面 |
| 列表默认 | 每页 20 条；查询条件与列设置本地持久化（按用户 + 路由维度） |
| 键盘与无障碍 | 表格与表单可键盘操作；按钮有 aria-label；仅用颜色区分状态时同时提供文案 |

## 8. 响应式与兼容

| 断点 | 行为 |
|---|---|
| ≥ 1440 | 侧边栏展开，表格全部列可见 |
| 1280–1440 | 侧边栏展开，次要列可折叠 |
| 768–1280 | 侧边栏折叠为图标，查询区收起为「展开」 |
| < 768 | 侧边栏抽屉式，表格转卡片列表（仅保证可用，不做完整后台操作） |

兼容 Chrome / Edge / Firefox 最新两个大版本（见测试用例 TC-NFR-008）。

## 9. 前端目录结构

```
templates/admin/web/
├─ src/
│  ├─ api/            # 接口封装，一个模块一个文件
│  ├─ views/          # 页面，按模块分目录
│  ├─ components/     # CrudTable / DictSelect / FormDialog ...
│  ├─ layout/         # 侧边栏、顶栏、标签页
│  ├─ router/         # 静态路由 + 动态路由注入
│  ├─ store/          # Pinia：user / permission / dict / app
│  ├─ directives/     # permission.ts
│  └─ utils/request.ts# 统一请求层（token、traceId、错误码、无感刷新）
└─ .env.*             # VITE_API_BASE 等，按环境区分
```

> 生成器产出落地到 `web/src/views/<model>/` 与 `web/src/api/<model>.ts`（与 PRD-006 目录约定一致）。
